# 🤖 Study-Buddy-AI

> Learn Faster. Understand Better.

Study-Buddy-AI is an AI-powered study chatbot designed to help students ask questions, understand concepts, and receive study-oriented responses through a simple and interactive chat interface.

The project uses the Gemini API to generate AI responses and follows a simple frontend-backend architecture.

---

## ✨ Features

- 🤖 AI-powered study chatbot
- 📚 Get answers to study-related questions
- 💡 Helps explain concepts in a simple way
- 💬 Interactive chat interface
- 📝 Supports Markdown-formatted responses
- ⚡ Simple and responsive user experience
- 🔐 API key managed using environment variables

---

## 🛠️ Tech Stack

### Frontend

### Backend

- dotenv

### AI

- Google Gemini API
